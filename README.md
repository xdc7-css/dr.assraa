## 📌 نبذة عن المشروع (Overview)

نظام مساعد بصري وتفاعلي ذكي مخصص لدعم وتمكين المكفوفين وضعاف البصر في استكشاف محيطهم والتفاعل معه صوتياً ولحظياً.  
يعتمد المشروع بنية **حوسبة الحافة المحلية بالكامل (100% Offline Edge Architecture)**، حيث تعمل كافة نماذج الذكاء الاصطناعي على حاسوب المستخدم دون إرسال أي إطارات كاميرا أو تسجيلات صوتية إلى خوادم خارجية، مما يضمن أعلى درجات الخصوصية والاستجابة السريعة دون الحاجة للإنترنت.

---

## ⚙️ بنية النماذج والتقنيات (Architecture & Pipeline)

1. **نموذج الرؤية واللغة (VLM):**
   - `Qwen3-VL-2B-Instruct` (مُدار محلياً عبر Ollama مع كبح التفكير الداخلي وحصره في الردود الوصفية الإرشادية المباشرة بالعربية).
2. **كشف الكائنات وتحديد المواقع (Object Detection):**
   - `YOLO11n` (خفيف وسريع، مع تنعيم زمني ودعم تحديد اتجاهات اليمين/الوسط/اليسار).
3. **التعرف الضوئي على النصوص (OCR):**
   - `EasyOCR` (ثنائي اللغة: عربي / إنجليزي مع ضبط اتجاه الأحرف العربية وتشكيلها).
4. **التعرف الآلي على الكلام (ASR):**
   - `faster-whisper` (تفريغ صوتي سريع محلي يدعم اللهجة العراقية والعربية الفصحى).
5. **توليد النطق الصوتي (TTS):**
   - `Piper TTS` (النموذج العربي `ar_JO-kareem-medium` بسرعة طبيعية وقاموس نطق مصطلحات الواجهة).
6. **الواجهة الأمامية (Frontend):**
   - `React 18` + `TypeScript` + `Vite`.
   - نظام تصميم أكاديمي رصين مع خط `IBM Plex Sans Arabic` المدمج محلياً، ووضع التباين الفائق لضعاف البصر (`High Contrast Mode`).
7. **الواجهة الخلفية (Backend):**
   - `FastAPI` (Python 3.12) لمعالجة الطلبات وإدارة التزامن والإلغاء الفوري.

## 🚀 التشغيل السريع (Quick Start)

### 1. المتطلبات:
- نظام تشغيل Windows 10/11 (أو Linux).
- Python 3.12 مثبت ومفعل في بيئة افتراضية `.venv`.
- Node.js (v18+) لبناء الفرونت إند عند الحاجة.

### 2. تثبيت الحزم:
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 3. بناء الواجهة الأمامية (React):
```powershell
cd frontend
npm install
npm run build
cd ..
```

### 4. إطلاق التطبيق:
يمكن إطلاق التطبيق وسيرفر النماذج بأمر واحد:
```powershell
.\run_app.ps1
```
أو عبر الضغط المزدوج على:
```cmd
run_app.bat
```

يفتح التطبيق تلقائياً في المتصفح على الرابط:
**`http://localhost:8000`**

## 📂 هيكل المشروع (Project Structure)

```text
asraa-project/
├── app/
│   ├── main.py                  # خادم FastAPI ونقاط النهاية
│   ├── orchestrator.py          # منسق النوايا وتوجيه النماذج
│   ├── schemas.py               # نماذج البيانات Pydantic
│   ├── config.py                # الإعدادات ومسارات النماذج
│   ├── adapters/                # محولات النماذج (VLM, OCR, YOLO, TTS, ASR)
│   └── static/                  # الأصول الثابتة المجمعة والخطوط
├── frontend/                    # كود الواجهة الأمامية (React + TS + Vite)
│   ├── src/                     # المكونات، نظام التصميم، وإعدادات الهوية
│   └── public/                  # خطوط IBM Plex Sans Arabic ورخصة OFL
├── scripts/                     # سكربتات فحص النظام وتوليد العينات
├── tests/                       # اختبارات الأداء والتكامل الآلية (pytest)
├── models_manifest.json         # التوثيق الرسمي لإصدارات وبصمات النماذج
├── requirements.txt             # متطلبات بايثون
├── run_app.ps1                  # سكربت التشغيل الرئيسي (PowerShell)
└── run_app.bat                  # سكربت التشغيل السريع (Batch)
```
