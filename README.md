## نبذة عن المشروع (Overview)

نظام مساعد بصري وتفاعلي ذكي مخصص لدعم وتمكين المكفوفين وضعاف البصر في استكشاف محيطهم والتفاعل معه صوتياً ولحظياً.  
يعتمد المشروع بنية **حوسبة الحافة المحلية بالكامل (100% Offline Edge Architecture)**، حيث تعمل كافة نماذج الذكاء الاصطناعي على حاسوب المستخدم دون إرسال أي إطارات كاميرا أو تسجيلات صوتية إلى خوادم خارجية، مما يضمن أعلى درجات الخصوصية والاستجابة السريعة دون الحاجة للإنترنت.

---

## ⚙️ بنية النماذج والتقنيات (Architecture & Pipeline)

1. **نموذج الرؤية واللغة (VLM):**
   - `Qwen3-VL-2B-Instruct` (مُدار محلياً عبر Ollama مع كبح التفكير الداخلي وحصره في الردود الوصفية الإرشادية المباشرة بالعربية).
2. **كشف الكائنات وتحديد المواقع (Object Detection):**
   - `YOLO11n` (خفيف وسريع، مع تنعيم زمني ودعم تحديد اتجاهات اليمين/الوسط/اليسار).
3. **التعرف الضوئي على النصوص (OCR):**
   - `EasyOCR` (ثنائي اللغة: عربي / إنجليزي مع ضبط اتجاه الأحرف العربية وتشكيلها).
4. **التعرف الآلي على الكلام (ASR):**
   - `faster-whisper` (تفريغ صوتي سريع محلي يدعم اللهجة العراقية والعربية الفصحى).
5. **توليد النطق الصوتي (TTS):**
   - `Piper TTS` (النموذج العربي `ar_JO-kareem-medium` بسرعة طبيعية وقاموس نطق مصطلحات الواجهة).
6. **الواجهة الأمامية (Frontend):**
   - `React 18` + `TypeScript` + `Vite`.
   - نظام تصميم أكاديمي رصين مع خط `IBM Plex Sans Arabic` المدمج محلياً، ووضع التباين الفائق لضعاف البصر (`High Contrast Mode`).
7. **الواجهة الخلفية (Backend):**
   - `FastAPI` (Python 3.12) لمعالجة الطلبات وإدارة التزامن والإلغاء الفوري.

## 🚀 التشغيل السريع (Quick Start)

### 1. المتطلبات:
- نظام تشغيل Windows 10/11 (أو Linux).
- Python 3.12 مثبت ومفعل في بيئة افتراضية `.venv`.
- Node.js (v18+) لبناء الفرونت إند عند الحاجة.

### 2. تثبيت الحزم:
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 3. بناء الواجهة الأمامية (React):
```powershell
cd frontend
npm install
npm run build
cd ..
```

### 4. إطلاق التطبيق (التشغيل بأمر واحد):
يمكن إطلاق التطبيق وسيرفر النماذج بالكامل بأمر واحد فقط من موجه الأوامر (PowerShell أو CMD):
```powershell
python run
```
أو:
```powershell
python run.py
```
*(أو عبر استخدام السكربتات المساعدة: `.\run_app.ps1` أو `run_app.bat`)*

يقوم الأمر تلقائياً بالتحقق من البيئة الافتراضية `.venv`، وتأكيد تشغيل خدمة Ollama ونموذج Qwen3-VL 2B، ثم تشغيل خادم FastAPI وفتح واجهة الويب تلقائياً في المتصفح الافتراضي على الرابط:
**`http://127.0.0.1:8000`**

## ✨ الترقيات والميزات الجديدة (Graduation Upgrades)

### 1. الإرشاد الذكي لجودة الصورة (Smart Image-Quality Guidance):
- **فحص سريع قبل النماذج الثقيلة:** فحص فوري خلال **4.69 مللي ثانية**.
- **كشف حالات الإضاءة والتشويش:**
  - إضاءة خافتة: *«الإضاءة قليلة، جرّب مكان أضوى.»*
  - إضاءة ساطعة/وهج: *«الإضاءة ساطعة جداً، عدّل زاوية الكاميرا.»*
  - اهتزاز وضبابية: *«ثبّت الكاميرا لحظة.»*
  - إطار فارغ أو انقطاع الكاميرا: *«الكاميرا غير متصلة أو الإطار فارغ.»*
- **إرشاد موضعة المستندات (OCR):** توجيه المستخدم لتقريب الورقة أو تعديل الزاوية (*«قرّب الورقة شوي»*).
- **كبح التحذيرات المكررة والتجاوز اليدوي:** مؤقت زمني لعدم إزعاج المستخدم الصوتي، مع زر لتجاوز الفحص (*تجاهل التحذير واستمر*).

### 2. جلسة البحث المستمر عن الأغراض (Continuous Object Search):
- تحويل أمر «ابحث عن غرض» إلى جلسة تفاعلية متصلة قابلة للإلغاء.
- **تحديث اتجاهات الكائن بصرياً:** تحديد الاتجاه بالنسبة للصورة (*«يمين الصورة»*، *«وسط الصورة»*، *«يسار الصورة»*).
- **إعلان الاختفاء عند الثبات:** إذا غاب الكائن لمدة إطارين متتاليين يعلن النظام: *«هسه ما أشوفها.»*
- **قاموس مرادفات اللهجة العراقية:** دعم مسميات مثل:
  - `بطل`، `دولكة`، `ماي` -> قنينة (Bottle).
  - `قنفة`، `تخم` -> أريكة (Couch).
  - `استكان`، `قلاص` -> كوب (Cup).
  - `شاشة` -> تلفزيون (TV).
  - `حاسبة`، `لابتوب` -> حاسوب (Laptop).
  - `بزونة` -> قطة (Cat).
- **شرح الأغراض غير المدعومة بأمان:** توضيح عدم قدرة النموذج على كشف عناصر الحركة كالأبواب والأدراج دون ادعاء صلاحيته للتوجيه الحركي الحرج.

### 3. سياق المحادثة القصير والذاكرة المؤقتة (Short Conversational Context):
- ذاكرة جلسة مؤقتة في الرام (5 دقائق صلاحية) تحفظ آخر استجابة، آخر كائن، ومهمة المستخدم.
- **التكرار الفوري دون إعادة استدلال:** أمر «كرر» أو «عيد الجواب» يعيد القراءة الصوتية للنص السابق فوراً دون تشغيل الكاميرا أو النماذج.
- **اختصار الجواب:** أمر «اختصر الجواب» يكثّف الإجابة دون اختلاق أو إضافة حقائق جديدة.
- **حل الضمائر:** مثل «وينها؟» تشير تلقائياً لآخر كائن تم الاستفسار عنه.
- **مسح الذاكرة:** أمر «امسح الذاكرة» يفرغ السياق مباشرة لضمان الخصوصية.

### 4. الوضع المزدوج للرؤية واللغة ومقارنة 2B مقابل 4B العادلة:
- **الوضع الافتراضي السريع (Fast - 2B):**
  - نموذج `qwen3-vl:2b-instruct-q4_K_M` محلي 100% داخل ذاكرة كارت الشاشة (GPU VRAM ~1.9 GB).
  - استجابة فائقة السرعة (**2.3 ثانية**) مناسبة للتفاعل الصوتي الحي.
- **الوضع المفصّل الاختياري (Detailed - 4B):**
  - نموذج `qwen3-vl:4b-instruct-q4_K_M` بحجم 3.3 GB.
  - قياس توزيع الطبقات الحقيقي على بطاقة `GTX 1650 Ti` (4GB VRAM): تبيّن توزيع Ollama للطبقات بواقع **14 من 37 طبقة على كارت الشاشة (1062 MiB VRAM)** و **23 طبقة على ذاكرة النظام (1618 MiB Host RAM)**.
  - القرار التقني الأمين: جعل 2B هو الوضع الافتراضي لسرعته، وترك 4B كخيار إضافي عند طلب الفحص الدقيق، مع تفريغ الذاكرة تلقائياً لمنع أخطاء نفاد الذاكرة (CUDA Out of Memory).

### 5. إمكانية الوصول والمؤشرات الصوتية (Accessible Controls):
- نغمات Web Audio API محلية خفيفة عند بدء الاستماع ونهايته وتأكيد كشف الكائنات.
- أزرار التحكم بسرعة النطق (0.75x، 1.0x، 1.25x، 1.5x) متوافقة مع محرك Piper TTS.
- تحكم كامل بلوحة المفاتيح: `Esc` للإلغاء الفوري وتفريغ قوائم النطق، `Space` للمايكروفون، `R` للتكرار، `S` للاختصار.
- واجهة تباين فائق (High Contrast Mode) مع تركيز مرئي واضح لقارئات الشاشة.

## 📂 هيكل المشروع (Project Structure)
