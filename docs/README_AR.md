# المساعد البصري الذكي متعدد الوسائط لمساعدة المكفوفين وضعاف البصر
### مشروع تخرج: تصميم وتطوير مساعد ذكي قائم على الذكاء الاصطناعي متعدد الوسائط للتفاعل الصوتي والتعرف على البيئة المحيطة لحظياً

---

## 1. نبذة عن المشروع
هذا المشروع عبارة عن نموذج أولي تطبيقي متكامل، مصمم ليعمل محلياً بالكامل على الحاسوب (Edge Computing) بدون الحاجة إلى اشتراكات سحابية مدفوعة أو إرسال صور وتسجيلات المستخدم إلى خوادم خارجية، مما يضمن أقصى درجات الخصوصية والأمان مع الامتثال الصارم لقيود الذاكرة والموارد.

يقوم النظام بدمج خمسة نماذج ذكاء اصطناعي ونظام تحليل جودة في دورة تفاعلية متناسقة:
1. **التعرف الصوتي (ASR):** تحويل كلام المستخدم باللغة العربية إلى نص باستخدام `faster-whisper` (Base INT8 على المعالج).
2. **توجيه النوايا الذكي (Intent Router):** تصنيف الأمر صوتياً أو كتابياً بدقة 100% (20 حالة اختبار) مع دعم اللهجة العراقية والفصحى.
3. **محلل جودة الصورة (Frame Quality Analyzer):** فحص فوري للتعريض (الإعتام الشديد أو السطوع المفرط) والتشويش الحركي (Laplacian Blur) مع توجيهات صوتية فورية.
4. **كاشف الكائنات والتموضع المكاني (Detection):** رصد الكائنات اليومية وتحديد موقعها (يمين، يسار، وسط) بالنسبة لنظرة المستخدم مع التنعيم الزمني ودعم مرآة الكاميرا باستخدام `YOLO11n`.
5. **التعرف الضوئي على الحروف (OCR):** قراءة اللوحات الإرشادية والمستندات المطبوعة باللغتين مع ترتيب الأسطر عمودياً وأفقياً من اليمين لليسار وتحسين التباين التكيفي (CLAHE) باستخدام `EasyOCR`.
6. **الإجابة البصرية وتوليد الأوصاف (VLM):** الإجابة عن الأسئلة البصرية المعقدة ووصف المشهد بدقة عبر نموذج `Qwen3-VL 2B` على معالج الرسوميات NVIDIA GTX 1650 Ti عبر `Ollama`.
7. **النطق والتركيب الصوتي العربي (TTS):** نطق الإجابات بصوت عربي واضح وطبيعي بتردد 22.05 كيلوهرتز باستخدام محرك `Piper` وبصوت `ar_JO-kareem-medium`.

## 2. متطلبات التشغيل
- **نظام التشغيل:** Windows 11 / Windows 10 (64-bit)
- **بيئة بايثون:** Python 3.12 (تم إعداد البيئة الافتراضية المحلية `.venv` على القرص X:)
- **الأجهزة الملحقة:** كاميرا ويب وميكروفون وسماعات صوت.
- **بطاقة الرسوميات:** NVIDIA GeForce GTX 1650 Ti (4GB VRAM) أو تشغيل على المعالج.
- **خدمة Ollama:** مثبتة محلياً بالكامل على القرص X: داخل `tools/Ollama/` والنماذج داخل `models/ollama/`.

## 3. طريقة التشغيل بنقرة واحدة
افتح موجه أوامر PowerShell داخل مجلد المشروع ونفذ:
```powershell
.\run_app.ps1
```
أو انقر مرتين على ملف:
```cmd
run_app.bat
```
سيقوم السكريبت بالتحقق من النماذج وخدمة Ollama وتشغيل الخادم فوراً على الرابط:
👉 **`http://localhost:8000`**

افتح متصفح Chrome أو Edge للدخول إلى واجهة المستخدم (حيث يتوفر سياق آمن للكاميرا والميكروفون على localhost).

## 4. دليل الاستخدام والأوامر الصوتية السريعة

الواجهة تدعم التحكم الكامل بالفأرة أو عبر اختصارات لوحة المفاتيح للمكفوفين:

| الأمر / الوظيفة | الاختصار | العبارات الصوتية المدعومة (بالفصحى واللهجة العراقية) |
| :--- | :---: | :--- |
| **اضغط للتحدث (PTT)** | `Space` (مسافة) | اضغط واستمر بالضغط للتحدث، ثم ارفع يدك عند الانتهاء. |
| **تشغيل/إيقاف الكاميرا** | `C` | تشغيل بث الكاميرا المباشر للرؤية. |
| **صف المشهد** | `D` | "شنو قدامي؟"، "شنو كدامي هسة؟"، "صف المشهد"، "ماذا يوجد أمامي؟". |
| **اقرأ المكتوب** | `R` | "اقرأ المكتوب"، "اقرأ النص بالصورة"، "شنو مكتوب على الورقة؟". |
| **أين الكائن؟ (تحديد المكان)** | `F` | "وين القنينة؟"، "وين الكرسي؟"، "وين اللابتوب؟"، "شوفلي وين الكوب". |
| **كرر الجواب** | `A` | "كرر"، "عيد الجواب"، "شنو كلت ما سمعتك؟" (تكرار فوري < 5 مللي ثانية دون إعادة تشغيل النماذج). |
| **إيقاف الصوت فوراً** | `Esc` | إيقاف نطق المساعد فوراً وإلغاء أي طلب قيد المعالجة. |

*ملاحظة هامة:* تم عزل اختصارات لوحة المفاتيح برمجياً بحيث لا يتم تفعيلها عن طريق الخطأ أثناء الكتابة داخل حقول النصوص.

## 6. استكشاف الأخطاء الشائعة وحلها (Troubleshooting)

1. **المتصفح لا يشغل الصوت تلقائياً:**
   - سياسات الأمان في المتصفحات تمنع التشغيل التلقائي للصوت (Autoplay) دون تفاعل المستخدم. في هذه الحالة، ستجد زراً بارزاً بعنوان **"🔊 استمع للإجابة"** فور انتهاء المعالجة؛ انقر عليه لسماع الصوت.
2. **الكاميرا لا تعمل:**
   - تأكد من منح الإذن للمتصفح بالوصول إلى الكاميرا من شريط العنوان.
   - تأكد من عدم استخدام الكاميرا من قبل تطبيق آخر.
3. **تنبيه الإعتام أو التشويش:**
   - إذا ظهر تنبيه صوتي بأن "الصورة مظلمة"، يرجى توجيه الكاميرا لمصدر ضوء لضمان قدرة نماذج الرؤية على العمل.
4. **حدود المسؤولية وإخلاء مسؤولية الملاحة:**
   - هذا النظام مخصص لتقديم **المعلومات البصرية والمساعدة التفاعلية**، ولا يدعي توفير الملاحة المستقلة الآمنة أو قياس المسافات الدقيقة أو تجنب الحفر والسلالم.
